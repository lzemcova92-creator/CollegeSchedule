# 📅 Расписание Колледжа

Desktop-приложение на WPF для составления и просмотра расписания занятий колледжа. Система автоматически проверяет конфликты (аудитория занята, преподаватель ведет две пары, группа в двух местах) и позволяет администратору управлять всеми сущностями.

## 🛠 Стек технологий
* **Язык:** C# 12 / .NET 8 (WPF)
* **Архитектура:** MVVM (CommunityToolkit.Mvvm), Clean Architecture
* **База данных:** SQLite + Entity Framework Core (Code First)
* **Библиотеки:** iText7 (PDF-отчеты), ClosedXML (Excel-отчеты)
* **Дизайн:** Тёмная тема (Slate + Indigo), кастомные анимации, без стандартных серых DataGrid.

## 🚀 Как запустить
1. Установите [Visual Studio 2022](https://visualstudio.microsoft.com/) с нагрузкой «Разработка классических приложений .NET».
2. Склонируйте репозиторий или откройте файл `Project1.sln`.
3. Дождитесь восстановления NuGet-пакетов.
4. Нажмите `F5` (Запустить).

*При первом запуске база данных `college.db` создастся автоматически и заполнится тестовыми данными (сидер).*

## 🏗 Архитектура проекта
* `Project1.App` — WPF-приложение (точка входа, окна, code-behind).
* `Project1.Core` — Модели данных, перечисления, интерфейсы.
* `Project1.Data` — DbContext, Seeder, PasswordHasher, миграции.
* `Project1.Services` — Бизнес-логика (авторизация, проверка конфликтов, отчеты, аудит).
* `Project1.UI` — ViewModels, конвертеры, глобальные стили (Colors.xaml, Styles.xaml).
* `Project1.Tests` — Unit-тесты (если есть).

## 📦 Основные функции
* **Авторизация и роли:** 3 роли (Админ, Преподаватель, Студент).
* **Управление расписанием:** Сетка по дням недели, проверка конфликтов при добавлении.
* **Управление практикой:** Назначение периодов практики для групп (скрывает обычное расписание).
* **Свободные кабинеты:** Поиск свободных аудиторий на выбранный день и пару.
* **CRUD:** Пользователи, Группы, Преподаватели, Аудитории, Предметы.
* **Отчеты:** Экспорт в PDF (расписание) и Excel (нагрузка преподавателей).
* **Резервное копирование:** Создание и восстановление базы данных.
* **Журнал действий:** Логирование всех действий администратора.
